# ربات تلگرام سفارشی

سیستم آپلود/لینک‌دهی فایلِ نسخهٔ اولیه حذف شده است. امکانات فعلی:

- جوین اجباری با متن ثابت و دکمه‌های اینلاین عضویت/بررسی
- پایش خروج عضو از کانال/گروه اجباری؛ اطلاع لغو اشتراک و نمایش دوبارهٔ درخواست جوین
- پیام شروع چندبخشی و دکمه‌های سفارشی اعضا در منوی پایین چت (Reply Keyboard)
- ارسال همگانی چندپیامه با تأیید نهایی
- بکاپ JSON به پیوی مالک هنگام راه‌اندازی و هر 24 ساعت؛ ارسال همان فایل JSON به پیوی ربات، فقط توسط مالک، تنظیمات و دکمه‌ها و فهرست اعضا را بازیابی می‌کند

## راه‌اندازی و امنیت

مقادیر محرمانه در فایل خصوصی `.env` نگهداری می‌شوند. اجرای مستقیم `main.py` یا `bot_app.py` این فایل را می‌خواند. `.env` در ZIP و Docker image قرار نمی‌گیرد؛ برای Docker، مقادیر را در Environment Variables هاست تنظیم کنید. فایل‌های `env.example` و `config.example.json` نمونه‌اند.

مالک باید یک‌بار `/start` بزند تا ربات بتواند بکاپ را در پیوی او بفرستد. برای دریافت رویداد فوری خروج، ربات باید در هر کانال/گروه اجباری ادمین باشد. مدیران ربات هم از شرط عضویت و اعلان لغو اشتراک مستثنا نیستند؛ همهٔ مسیرهای ارسال محتوای اعضا عضویت را دوباره بررسی می‌کنند. پس از Deploy نسخهٔ جدید، هنگام آزمایش خروج در لاگ باید رویداد `Membership update` دیده شود؛ اگر دیده نشد، دسترسی ادمین ربات و تنظیم شناسه/نام کانال اجباری را بررسی کنید. برای ماندگاری داده‌ها پس از Deploy مجدد، Volume پایدار را روی `/app/data` متصل کنید. توکن و کلیدهای API را در Git یا بسته‌های قابل‌اشتراک قرار ندهید.
